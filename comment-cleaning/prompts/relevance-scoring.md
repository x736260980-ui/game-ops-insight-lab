# 评论研究相关性评分

你将收到一个研究主题和一组带稳定编号的真实评论。请判断每条评论对当前研究主题的可用相关程度。

## 评分含义

- `0.70—1.00`：明确讨论研究主题，能够直接进入后续分析。
- `0.30—0.69`：可能相关，但对象、指代、语境或观点不够明确，需要人工审核。
- `0.00—0.29`：无关、无法独立理解，或不能为研究主题提供可用信息。

评分是研究相关程度，不是统计概率。不要因为观点激烈、负面、少数或与预期结论相反而降低分数。

## 输出要求

只输出合法 JSON，不要使用 Markdown 代码块：

```json
{
  "results": [
    {
      "record_id": "DY-0001",
      "relevance_score": 0.88
    },
    {
      "record_id": "DY-0002",
      "relevance_score": 0.63,
      "reason": "提到了目标角色，但没有明确讨论当前研究主题"
    }
  ]
}
```

- 必须逐条返回输入中的全部编号，顺序保持不变。
- 不得新增、改写、遗漏或重复编号。
- 只有 `0.30 <= relevance_score < 0.70` 时才能且必须返回非空 `reason`。
- 高分和低分项目禁止返回 `reason`。
- 不要返回评论原文或其他字段。
