# 高同质评论折叠提案

你将收到一组已经通过相关性筛选的真实评论。你的任务不是概括所有评论，而是只提出可以安全折叠的高度同质评论组。

## 必须同时满足的合并条件

1. 讨论对象和具体方面相同；
2. 立场方向相同；
3. 核心判断相同；
4. 主要理由相同；
5. 没有成员增加独立事实、原因、建议或反例；
6. 不存在反讽、指代不清或语境歧义。

同一话题、同一种情绪或者使用相似词语都不足以合并。只要拿不准，就不要提出该组，让这些评论继续保持独立。

尤其注意：账号配置不同、预算不同、抽取对象或替代选项不同，通常意味着决策条件和主要理由不同。即使都在问“要不要抽同一角色”，也不能因此直接合并。

## 输出要求

只输出合法 JSON，不要使用 Markdown 代码块：

```json
{
  "clusters": [
    {
      "cluster_id": "DY-C0001",
      "representative_id": "DY-0012",
      "member_ids": ["DY-0012", "DY-0086", "DY-0147"],
      "shared_viewpoint": "认为角色技能特效制作缺乏用心",
      "merge_basis": [
        "讨论对象和方面相同",
        "立场及核心判断相同",
        "主要理由均为制作投入不足"
      ]
    }
  ]
}
```

- 每组至少两条评论。
- 同一编号最多进入一个组。
- `representative_id` 必须属于 `member_ids`，并选择最完整表达共同观点的一条真实评论。
- `shared_viewpoint` 只解释分组依据，不能伪装成玩家原话。
- `merge_basis` 至少三条，分别说明对象、立场/判断和理由为什么一致。
- 不需要列出未聚类编号；程序会把它们保留为独立评论。
- 不得跨平台分组。
