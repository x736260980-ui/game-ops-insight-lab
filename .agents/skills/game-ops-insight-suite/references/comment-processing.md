# 评论处理

## 顺序

```text
原始采集 → 去空与确定性噪声 → 稳定编号 → 主题相关性 → 高同质折叠 → 统一分析输入
```

## 相关性

- 先冻结核心对象、核心问题、允许的关联路径和明确排除范围。
- 保留直接相关、原因相关、结果相关、边界相关和反向意见。
- 同一游戏但不能回答当前问题的评论应排除。
- 不因评论短、口语化、有错别字、玩梗或持少数立场而排除。
- 相关性不等于事实正确，也不等于赞同主流批评。

## 同质折叠

- 只折叠语义和立场高度一致、可以由同一代表句承载的表达。
- 不合并理由不同、对象不同、褒贬不同或只共享关键词的评论。
- 代表记录保留稳定 ID，`support_count` 等于该组包含的原始表达数。
- 计数必须满足折叠前后数量守恒，成员 ID 不得重复出现在多个组。

提示与 Schema 位于 `comment-cleaning/`，确定性脚本位于 `scripts/`。
