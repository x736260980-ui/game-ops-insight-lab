# 三平台采集

项目使用本地 MediaCrawler FastAPI：抖音 `8101`、Bilibili `8102`、小红书 `8103`。首次使用在可见 Chrome 中分别登录，之后复用本机浏览器资料；不得复制或打印 Cookie。

## 共同规则

- 一个平台的一次研究任务尽量合并为一个 `collect-task` 请求。
- 用户指定的 aweme ID、BV 号或小红书完整笔记链接必须保留，不得用搜索结果替换。
- 关键词搜索和固定内容合并后按平台内容 ID 去重。
- 默认只采集一级评论；不下载图片、视频或用户主页。
- 单次任务最多选择 20 个内容，并保持低并发和合理频率。
- 平台实际返回少于请求数量时如实记录，不补造数据。
- `partial_success` 保留成功内容并报告失败项，不自动重跑整批。

请求 Schema 位于项目根目录 `schemas/`。服务启动脚本位于 `scripts/run_*_api.ps1`。
