# 路由规则

## Single 与 Dual

- `single`：普通版本反馈、边界清楚、证据冲突较少的事件。
- `dual`：争议大、反例多、商业影响或事实边界容易被过度推断的事件。
- 两者互斥。只有明确做方法对照评测时，才在独立分支中分别运行。

## 历史复核

- 必须先生成当前事件初判。
- 使用自然语言查询、可选情绪和当前事件排除条件。
- 读取历史事件的动态类别名称、定义、摘要和命中评论；不得依赖统一 category ID。
- 历史案例用于比较、质疑、发现边界，不得替代当前事件证据。

## 可选路线

- Persona：只在用户需要玩家反应模拟或回测时启用。模拟前不得读取当前事件真实玩家结论。
- 网页资料：仅作背景、佐证与反例，不进入评论统计。

## Executor

`codex`、`automation`、`manual` 只描述执行方式；完成状态统一为 `completed`。执行方式不改变文件契约。
